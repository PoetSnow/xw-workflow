# 检测项起草到审批

供核实。先做知识库上传，做到能看见效果再做项目和审批。

文件是 PDF。行业、项目类型在上传这一屏就填写，可以多选。一套资料可以同时适用多种项目。Agent 不在起草时猜测这些范围。

现在的知识库表只有一个 `domain`，写不下多种行业和多种项目类型，也不能解析 PDF。原文仍进现有的文档表和切块表。适用范围放在旁边的法规目录里。

## 先看到的效果

用一份同时适用于「储罐」和「管道」的化工法规 PDF 验收。

1. 上传 PDF，不填行业或项目类型，不能发布。一份化工项目匹配不到它。
2. 同一屏填行业「化工」，项目类型「储罐」「管道」，确认发布。页面能看到抽出的适用范围原文和条款号。
3. 新建项目，行业化工、类型储罐：这份资料出现。类型改成锅炉：不出现。
4. 只改目录里的项目类型，加上「装卸」，不必重新上传 PDF。装卸项目立刻能匹配到。储罐项目不受影响。
5. 对储罐项目列检测项：检测项带这份 PDF 的条款号和原文。锅炉项目不能对这份资料列检测项。

这五步没通过，不做审批。

## 上传

上传页在检测项目模块。一次提交这些内容：

| 字段 | 谁填 | 说明 |
| --- | --- | --- |
| PDF | 维护人 | 当前有效版本。扫描件如果抽不出文字，发布失败 |
| 名称、标准号 | 维护人 | 模型可以按首页预填，以人提交的为准 |
| 行业 | 维护人，可多选 | 不预填也能保存，但不能发布 |
| 项目类型 | 维护人，可多选 | 同一份 PDF 勾选多种项目 |
| 资料集编号 | 系统 | 用标准号。底座只把它当作编号 |

发布前系统做三件事：抽出 PDF 文本，按「第×条」切块写入现有知识库，把适用范围那一条展示在确认页上。确认页同时显示已填的行业和项目类型。维护人点确认后，目录状态变为已发布。

未确认、抽不出文字、或行业和项目类型有一个为空，目录状态保持未发布。未发布的资料不参加项目匹配，也不能被检索进检测项。

行业和项目类型存在法规目录，不写入 `agent_knowledge_document` 或 `agent_knowledge_chunk`。切块里的条款号写在标题或片段开头，供检测项引用。

## 维护

改适用范围不重新解析 PDF，也不重新做向量。

| 操作 | 做什么 | 已经发布的项目 |
| --- | --- | --- |
| 改正行业或项目类型 | 只改目录 | 草稿重新匹配。审批中和已通过的项目保持提交时的那份清单 |
| 换一版 PDF | 新编号入库，旧编号标为废止 | 新草稿不再匹配旧版。已提交项目仍引用旧版条款 |
| 废止 | 目录标废止 | 新草稿不再出现。原文和切块保留，旧依据还能打开 |
| 抽文本失败 | 不发布 | 无匹配 |

目录至少这些字段：资料集编号、名称、标准号、行业列表、项目类型列表、状态（未发布、已发布、废止）、适用范围依据（文档 Id、切块 Id、条款号、片段）。

新表只提交 `docs/sql/`。代码里不建表。

## 项目里怎么用

草稿填写行业、项目类型、介质、新建或改扩建。系统用前两项查已发布目录：目录的行业包含项目行业，且目录的项目类型包含项目的项目类型。查到的来源是 `matched`。负责人可以去掉，也可以从已发布目录里另补，补入的来源是 `manual`。

没有留下的资料集，不能列检测项。

列检测项只把留下的编号放进作业的 `corpusIds`。处理器只在这些编号里检索原文，输出检测项、法规要求和依据。依据包含资料集、文档 Id、切块 Id、条款号、片段。再次分析不覆盖已经人工改过或人手添加的行。

介质和建设性质只放进这次作业的 `input`，不参与选哪些 PDF。

## 审批

检测项都有依据才允许提交。提交调用 `IApproveInstanceService.SubmitAsync`，`BusinessId` 为项目 Id。通过则 `approved`。驳回或撤销回到 `draft`，检测项还在。

检测项目模块实现 `IApproveCompletedHandler`。Agent 不参与审批。

## 顺序

1. PDF 能抽出文字并按条款检索。上传页必须带行业和项目类型，确认后才发布。完成上面五步验收。
2. 草稿按行业和项目类型列出资料，并只在这些资料里列出检测项。
3. 提交进现有审批，结束后回写项目状态。

前一步没达到，不开始下一步。

## 明确不做

- 不让模型在上传或起草时决定行业和项目类型。模型只预填名称和展示适用范围，人可以改。
- 不把行业、项目类型写入现有知识库表。
- 不靠一次全库向量检索决定该用哪份 PDF。
- 不在这条流程里对照实测值判定合规或不合规。
- 不把项目同步进 Agent。

## 核实

- 效果先出现在上传和匹配：同一份 PDF 勾选多种项目类型，只有对得上的项目能看见。
- 改项目类型不用重新上传。
- 检测项的依据来自该 PDF 的条款，不来自目录摘要。
- 未发布和已废止的 PDF 不会进新草稿。
