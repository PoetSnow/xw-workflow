# 产品售后服务管理规范
domain: aftersales

## 1. 售后服务范围

本公司销售的智能检测设备提供售后服务支持。

售后服务范围包括：

1. 设备硬件故障检测
2. 软件系统升级
3. 设备联网异常处理
4. 使用操作指导

以下情况不属于免费售后范围：

1. 人为损坏设备
2. 未按照操作规范使用设备导致的故障
3. 未授权拆卸设备内部结构
4. 超过服务期限的设备

人为损坏明确包括（但不限于）：

1. 摔落导致的损坏
2. 设备进水 / 液体进入机身
3. 私自拆卸、改装设备内部结构

### FAQ：设备进水是否保修？

问题：设备进水以后还能免费维修吗？

答案：设备进水属于人为损坏，不属于免费保修范围。客户需自行承担维修及配件费用。若无法确认是否进水导致，请提交售后工单由工程师鉴定。


## 2. 设备保修政策

设备自购买日期开始计算保修期限。

标准设备保修期限：

- 主机设备：12个月
- 传感器组件：6个月
- 配套附件：3个月


保修期内：

如果设备出现非人为质量问题，公司提供免费维修服务。


保修期外：

客户需要承担维修产生的人工费用以及更换配件费用。


## 3. 售后申请流程

客户发现设备异常后，需要按照以下流程提交售后申请：

第一步：

客户通过系统提交售后申请。

需要填写：

- 设备编号
- 故障描述
- 联系方式


第二步：

售后人员审核问题信息。

如果无法远程解决，则安排设备返修。


第三步：

维修完成后，售后人员更新维修记录，并通知客户。


## 4. 常见问题处理

### 设备无法联网

处理步骤：

1. 检查设备网络连接是否正常。
2. 确认设备是否绑定正确账号。
3. 检查服务器服务状态。
4. 如果仍无法连接，提交售后工单。


### 设备无法启动

处理步骤：

1. 检查电源连接。
2. 检查电源适配器状态。
3. 长按电源键重新启动。
4. 联系售后人员进一步处理。
