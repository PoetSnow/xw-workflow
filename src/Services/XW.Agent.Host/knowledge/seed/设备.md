# 仓库库存管理流程

## 1. 库存查询规则

系统库存由库存中心统一管理。

库存数量包含：

- 当前库存数量
- 已锁定数量
- 可用库存数量


库存计算公式：

可用库存 = 当前库存 - 已锁定库存


## 2. 产品库存查询

用户查询库存时，可以通过以下信息查询：

支持：

- 产品名称
- SKU编码
- 产品编号


例如：

用户输入：

"查询型号 NX100 的库存"

系统首先根据 SKU 或产品名称查询产品信息。

获取产品ID后，再查询库存记录。


## 3. 入库流程

仓库收到货物后，需要执行入库操作。


入库步骤：

第一步：

采购人员提交入库申请。


第二步：

仓库人员进行到货验收。


第三步：

系统生成入库单。


第四步：

库存数量自动增加。


## 4. 出库流程

商品销售或者领用时，需要执行出库操作。


出库步骤：

第一步：

创建出库单。


第二步：

仓库审核出库申请。


第三步：

系统扣减库存。


第四步：

生成库存流水记录。


## 5. 库存预警

系统支持库存预警。


当商品库存低于安全库存时：

系统生成库存预警。


库存管理员可以查看：

- 商品名称
- 当前库存
- 安全库存
- 建议采购数量
