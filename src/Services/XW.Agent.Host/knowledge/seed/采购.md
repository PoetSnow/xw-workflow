# 企业采购审批管理制度


## 1. 采购申请

员工采购物品，需要提交采购申请。

申请内容包括：

- 商品名称
- 数量
- 预算金额
- 使用部门
- 采购原因


## 2. 审批规则

采购金额不同，审批流程不同。


金额小于1000元：

部门负责人审批。


金额1000元至10000元：

需要部门负责人和财务审批。


金额超过10000元：

需要总经理审批。


## 3. 采购订单生成

审批通过后：

系统自动生成采购订单。


采购订单包含：

- 供应商信息
- 商品明细
- 数量
- 单价
- 交付日期


## 4. 采购入库

供应商交货后：

仓库执行验收。

验收通过：

生成入库单。

库存系统增加库存。
